# KNN 项目（第 8 周实践一）

手写 k 近邻算法，不调用 sklearn 的 KNN 核心；sklearn 只在对照实验里用。

## 目录

```
knn_project/
├── knn.py            # 手写 KNN 核心：距离、KNNClassifier、KNN 回归、工具函数
├── main.py           # 主程序：数据加载、预处理、训练、评估、绘图、交叉验证
├── README.md         # 项目说明、运行方式、依赖、实验结论
├── data/
│   └── dataset.csv   # 鸢尾花数据集（150 行 × 4 特征 + 类别）
└── plots/            # 运行后生成的图片
```

## 运行方式

```bash
cd knn_project
python main.py
```

一条命令按顺序跑完 13 个环节：工程环境 → 数据加载 → 预处理 → 距离函数 → 最近邻
→ 分类器 → 回归 → 评估 → 交叉验证选 k → 决策边界 → sklearn 对照
→ 异常与性能 → 自测（10 个测试用例）。

结果打印到控制台，图片保存到 `plots/`。

## 数据

`data/dataset.csv`：鸢尾花数据集，150 个样本、4 个数值特征
（`sepal_length`、`sepal_width`、`petal_length`、`petal_width`）、
3 个类别（setosa / versicolor / virginica）各 50 条，无缺失值，
标签列为 `species`（名称）与 `target`（0/1/2）。

## 实验结论

- 数据：150 × 4，3 类均衡，无缺失值；按 7:3 分层划分为 105 / 45。
- 标准化器只在训练集上拟合，测试集只做 transform，无信息泄漏；同种子划分结果完全一致。
- k=5 的手写 KNN 测试集准确率 **0.9333**（42/45），混淆矩阵显示错误只发生在
  versicolor 与 virginica 之间（3 个），setosa 全部正确。
- 5 折交叉验证选出 **k=6**（CV 准确率 0.9714），该 k 下测试集准确率 **0.9556**；
  k 太小过拟合（训练接近 1、CV 波动大），k 太大欠拟合（20 以上 CV 明显下降）。
- 与 sklearn 的 `KNeighborsClassifier` 在相同设置下：准确率同为 **0.9556**，
  45 个预测**完全一致**，近邻索引一致率 99.26%，距离最大差 2.2e-16。
  差异只来自浮点顺序、等距邻居排序与平票规则。
- KNN 回归（预测花瓣宽度）最优 k=8、等权均值：MAE 0.1747、R² 0.9037。
- 向量化距离计算比纯 Python 双层循环快约 **400 倍**（600×200×4 维：2.8s → 0.006s）。
- 10 个单元测试全部通过；空数据、维度不一致、k 越界、含 NaN、未训练就预测等
  8 类异常都会给出带说明的报错。
